# CareerDraft

CareerDraft is a career preparation app designed to help college students turn their experiences into clear résumé bullets, portfolio case studies, and career fair introductions.

## The Problem

Students often gain valuable skills through freelance work, entrepreneurship, volunteering, and class projects, but struggle to explain that experience in internship applications.

CareerDraft provides a guided workspace for organizing those experiences and communicating their value.

## Features

- **Experience-to-Skills Builder:** Organize responsibilities, tools, and outcomes into editable résumé bullet drafts.
- **Portfolio Case Study Builder:** Document a project's problem, audience, process, solution, and results.
- **Career Fair Preparation:** Draft a short introduction, review preparation checklists, and save recruiter questions.
- **Learning Library:** Explore practical lessons on résumé writing, project storytelling, and recruiter follow-ups.
- **Saved Drafts:** Keep work in the browser using local storage.

## Project Goals

- Make career preparation more approachable for students.
- Recognize skills gained through entrepreneurial and nontraditional experience.
- Translate a user problem into a functional, accessible product.

## Running Locally

Requires Node.js and npm.

1. Clone this repository.
2. Open a terminal in the project directory.
3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in the terminal.

## Data and Privacy

Drafts are stored in the user's browser. Clearing browser storage may remove saved work.

Example content is fictional and provided for demonstration. Generated résumé drafts should be reviewed and edited to accurately reflect the user's experience.

## Project Status

Independent portfolio project. This repository contains the source code; the app is not deployed as a public website.
